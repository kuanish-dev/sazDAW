# `daw-render`

Offline export to WAV/FLAC/MP3 and stems with loudness adjustment and a song range (`export/`, `encode/`, see "Audio export" ([docs/features/audio-export.md](../../docs/features/audio-export.md)); takes the engine through the `EngineFactory` contract, the concrete one is built by `daw-bootstrap`); the sound of a single track for bouncing to audio (`TrackRender`, `track.rs`, see "Rendering a track to audio" ([docs/features/bounce.md](../../docs/features/bounce.md))); project sound levels and each track's loudness in the mix, without files (`LevelMeter`: `MixAnalysis`, `analysis/`, the balance in `analysis/balance.rs`, see "Checking the result by ear" ([docs/features/mix-check.md](../../docs/features/mix-check.md))); the app's one set of BS.1770 / EBU R128 meters (`loudness.rs`: K-filter, momentary, short-term and integrated loudness, loudness range, true peak), shared by the export, the analysis and the live master meter (`LiveMeter`: `MasterMeter`, `live/`, fed by the engine's `MasterTap`, see "Live master meter" ([docs/features/master-meter.md](../../docs/features/master-meter.md))).

Depends on: contracts, hound, flacenc, mp3lame-encoder (LAME).

Map of the whole code: [ARCHITECTURE.md](../../ARCHITECTURE.md). Cross-layer features it takes part in: [audio-export](../../docs/features/audio-export.md), [bounce](../../docs/features/bounce.md), [master-meter](../../docs/features/master-meter.md), [mix-check](../../docs/features/mix-check.md), [recording](../../docs/features/recording.md), [tempo-map](../../docs/features/tempo-map.md), [warping](../../docs/features/warping.md).
