# `src/domain/` — domain logic (pure functions)

`src/domain/`: pure functions with no DOM and no state, one file per topic — time and grid (`time`), tempo map (`tempoMap`), the project changes taken into the interface's copy (`projectChanges`), clips and their selection (`clips`, `clipSelection`), notes (`pianoRoll`, `selection`, `steps`, `noteClip`, `pitch`), graph (`graph`), automation, kind catalog (`catalog`), samples and waveforms (`samples`, `waveform`, `clipWave`), mixer and knobs (`mixer`, `knob`), mixer strips from the graph (`mixerStrips`), the virtual stage (`stage`), drum part (`drumPart`), audio export (`exportAudio`), the live master meter (`masterMeter`), `math` (`clamp`)… Rules a UI gesture needs live here too, not in the gesture: clip trim/resize/gain (`clips`), the free span for a new automation clip (`automation: freeSpanAt`), which fade a tick is in (`fades: fadeAt`), the pencil stroke (`controllers`), the loop playhead (`noteClip: playheadInLoop`), a folder's M/S state (`trackRows: folderFlags`). No tests yet

Knows about: only the `api/types` types.
