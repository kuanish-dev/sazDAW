# `src/domain/` — domain logic (pure functions)

`src/domain/`: pure functions with no DOM and no state — time and grid (`time`), tempo map (`tempoMap`: ticks ↔ seconds and bars, point edits), clips and their selection (`clips`, `clipSelection`), notes (`pianoRoll`, `selection`, `steps`, `noteClip`, `pitch`), graph (`graph`), automation, kind catalog (`catalog`), samples and waveform (`samples`, `waveform`, `clipWave`, `dropSample`), mixer and knobs (`mixer`, `knob`, `envelope`), mixer strips from the graph (`mixerStrips`), a channel's utility units and neutral values (`channelUtility`), the virtual stage's geometry and channels (`stage`), drum part (`drumPart`), the part dialogs' number fields (`partFields`), new sampler tracks for a sound (`samplerTracks`), audio export choices and the request built from the export form (`exportAudio`), the live master meter's scales, numbers and vectorscope picture (`masterMeter`), `math` (`clamp`). Rules a UI gesture needs live here too, not in the gesture: clip trim/resize/gain (`clips`), the free span for a new automation clip (`automation: freeSpanAt`), which fade a tick is in (`fades: fadeAt`), the pencil stroke (`controllers`), the loop playhead (`noteClip: playheadInLoop`), a folder's M/S state (`trackRows: folderFlags`). No tests yet

Knows about: only the `api/types` types.
