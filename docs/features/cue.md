# Cue (start position) and the timeline ruler strip

- **Contract** (`TransportControl`, `daw-contracts/src/transport.rs`): `set_cue(Option<u64>)` / `cue()`. With a cue, `play()` from pause or stop first seeks to it (so pausing and pressing play again restarts from the cue, not where it paused), `stop()` returns to it (else to 0); `set_cue` itself does not move the playhead; while playing, `play()` does not jump. Implementation — one more atomic in `daw-transport` (`NO_CUE` = none), only the control side reads it, the audio thread is untouched; tests in `daw-transport/src/lib.rs`. Loading/creating a project clears the cue (`daw-project/src/service/mod.rs`). An audio take started from a stopped transport begins at the cue (`daw-audio-recorder`).
- **RPC/MCP:** `transport.setCue { tick | null }` (`daw-rpc/src/transport.rs`); the current cue is `cue` in the `tick` telemetry (`telemetry.rs`; `Tick.cue` in `api/types/transport.ts`). Mock — `mock/handlers/transport.ts` + `MockWorld.cue` (cleared by `install`).
- **UI.** `TransportActions.cueAt(tick)` (set the cue, then seek) and `clearCue()`. The ruler strip (the bar ruler) is a separate canvas: `ui/tracks/rulerRender.ts` draws bars, loop, signature and marker flags and the cue flag (geometry — `cueLayout.ts`); the rows canvas (`timelineRender.ts`) draws the marker lines, the loop shade and the dashed cue line; row coordinates start at 0 below the strip. Mouse on the strip: `tempoPointer` → `markerPointer` → `rulerPointer` (click — cue + seek, drag — loop, right-click on the cue flag — remove the cue, elsewhere — clear the loop). Layout (`TracksView.tsx`): the page scrolls vertically; the toolbar and the strip are `sticky` (the strip's `top` is the toolbar's measured height). CSS sticky does not work inside a horizontal scroller, so the strip sits outside the rows' `overflow-x-auto` in a clipped container whose `scrollLeft` is copied from the rows on `scroll`; `Timeline` renders the ruler into it through a `Portal` (from a fragment, so ruler events do not bubble into the rows' pointer). Both canvases draw only the visible window (`createScrollWindow` of the rows). Something similar above the rows (e.g. a chord lane): grow `RULER_HEIGHT`, draw in `rulerRender.ts`, add a `*Pointer.ts` to the strip's chain in `Timeline.tsx`.
