# Audio clip editing: fades, gain, trim, normalize, reverse

**Fades.** `Clip` fade lengths and shapes, set through `ClipEdit`; one formula `FadeShape::gain` (`daw-contracts/src/clips.rs`, allocation-free) that the engine applies per frame (`daw-engine/src/audio_voices.rs: fade_at`, on top of the crossfades), so export sounds the same. The frontend draws the curves with the same formulas (`domain/fades.ts: fadeGain`). Fade lengths are clamped to the clip length, with no other cap. A new shape: add the variant and its formula in both places.

**Trimming the start.** `ClipControl::trim_start` (RPC `clips.trimStart`): the left edge moves, the end and the content stay in place (an audio clip stops at the file start; a note clip's offset turns around its loop; the comp shifts with `take_rules::shift_comp`, also used by split). Pure rule: `daw-project/src/clip_rules.rs: trim_start`; the frontend preview and the mock share `domain/clips.ts: trimmedClip`.

**Normalize and reverse** (`ClipProcessing`, `daw-project/src/clip_processing.rs`). Two roles split by rule 8: the clip side decides what changes (gain; which sample and offset), the sample editor does the audio work through its contract (`SampleEditor::peak`, `SampleEditor::reverse_copy`). Normalize is non-destructive: it only sets the clip gain from the peak of the audio the clip plays. Reverse writes a reversed copy into the project folder (so it needs a saved project), imports it and points the clip at it with a mirrored offset, so the same piece plays backwards in place; it is a history group (import + clip edit), cancelled on failure; clips with several takes are refused. RPC: `clips.normalize`, `clips.reverse`. Mock: `mock/handlers/clips.ts` (no audio, so normalize assumes a fixed peak).

**Timeline UI.** `timelineRender.ts: drawAudioHandles` draws the fade curves, the fade handles and the gain line; hit-testing is in `timelineLayout.ts` (`audioZoneAt`, `gainLineY`), the drag rules in `domain/clips.ts` (`draggedGain`, `trimStartAt`) and `domain/fades.ts` (`fadeLengthAt`). `timelinePointer.ts` drags a fade handle, the gain line or the left edge (trim via `actions.clips.trimStart`); the edit is drawn as `ClipDraft.edited` until release and committed once. Right-click on an audio clip opens `ClipMenu.tsx` (normalize, reverse, fade shapes, delete); right-click on a note clip still deletes it. The toolbar gain slider goes up to `MAX_CLIP_GAIN`.
