# Audio export: formats, loudness, part of the song (`project.export`)

**Contract** (`daw-contracts/src/export.rs`): `Exporter::export(ExportRequest, progress) → ExportReport`. The request and the report (with their defaults and ranges) are described in the types; the dither rule is `ExportRequest::dithers`; `ExportRequest::new(path)` is the default request (for tests and the console). The report's loudness and true peak are of the mix as written (MP3: before compression); `null` means silence.

* **Order** (`daw-render/src/export/mod.rs`): everything checkable is checked before rendering (sample rate, `encode::check`, `loudness::check`) so a bad request does not fail after a long render; then the range (`range.rs`), the mix, then bus stems (`daw-render/src/stems.rs`, files `<mix>_<node>_<bus>.<extension>`). The file extension follows the format (`file_for_format`). The same offline engine plays (`load_engine`), seeked to the range start.
* **Part of the song** (`range.rs`): the length follows the tempo map plus the tail, at most one hour. Clips past the range end are removed or shortened to it, and a shortened clip loses its fade-out (otherwise the fade would move into the range), so the tail holds decaying effects and released notes, not the start of the next part. Notes started before the range start do not sound (as after seeking); an audio clip cut by the range end stops without a fade.
* **Formats** (`encode/`, trait `Encoder`; `write_file` creates the folder and deletes an unfinished file): WAV — hound (`wav.rs`); FLAC — `flacenc`, pure Rust, encoded block by block while rendering, the header rewritten at the end, 16/24 bits only (`flac.rs`); MP3 — LAME via `mp3lame-encoder`, CBR (`mp3.rs`; above 48 kHz LAME resamples down by itself; no Xing/LAME tag, so decoders play the encoder delay and the last frame's padding as silence, up to ~0.08 s). Rounding to integers is `pcm.rs: Quantizer`: TPDF dither with a fixed seed (export is reproducible), no noise shaping.
* **Loudness adjustment** (`loudness.rs`, `scratch.rs`): the mix is rendered once into a temporary float file (`<file>.render-tmp` next to the export) while measuring loudness and true peak (the shared meters in `daw-render/src/loudness.rs`); then the file is read back with one gain (up to the target, but not above the peak ceiling) into the export file, which is measured again for the report. There is no limiter: clipped peaks are distortion, so without enough headroom the file is quieter than the target, and `loudnessLufs` shows it. Stems get the same gain (sum of stems = mix). Why a file: an hour at 192 kHz does not fit in memory (~5.5 GB), and a second render doubles the time and may not sound the same (randomness in plugins); the price is disk space. The temporary file is deleted on failure too; if it cannot be deleted, the error names the path. Silence cannot be adjusted and is rejected. Loudness and peak are measured even without adjustment (cheap compared to rendering).
* **Licenses.** `flacenc` is Apache-2.0. LAME is LGPL: `mp3lame-sys` builds it from C sources at build time (a C compiler is needed — Xcode Command Line Tools) and links it statically. When distributing the app, include the LGPL text and a LAME notice and make it possible to rebuild the app with a modified LAME (for an open-source GPL project the sources are enough). Pure-Rust MP3 encoders were not chosen: `shine-rs` is also LGPL and lower quality, `rusty_mp3` is too young.
* **RPC** (`daw-rpc/src/project.rs`): `project.export` with a full description of the fields for the AI. **Interface:** `files/ExportDialog.tsx`; which settings apply to which format, the request built from the form, the path for the format (`pathForFormat`, as in the backend), the selected-clips range (`clipsRange`) and the result summary (`loudnessSummary`, flags a shortfall from the target) are `files/exportAudio.ts`; the result is a toast from the `audioExport.render` action (`files/audioExport.ts`). The mock (`mock/handlers/project.ts`) — extension by format, plausible numbers, the same rejections (FLAC float, no loop).
* **Tests:** JSON contract — `daw-contracts/src/export.rs`; encoders — `daw-render/src/encode/tests.rs`; dither — `encode/pcm.rs`; the meters — `daw-render/src/loudness.rs`; gain and ceiling — `export/loudness.rs`; range and loop — `export/range.rs`; temporary file — `export/scratch.rs`; the full session (loudness target and ceiling, silence, range and loop, FLAC/MP3 with stems) — `daw-bootstrap/tests/all/render_export.rs`; wire — `daw-rpc/tests/all/project.rs`.
* **Similar** (a new format): a module in `encode/` with an `Encoder`, an `ExportFormat` variant (+ `extension`), branches in `encode::open`/`check`, a filter in `api/dialogs.ts` and an entry in the dialog.
